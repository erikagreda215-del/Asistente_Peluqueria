*Asistente Virtual para Peluquería*

Chat con interfaz gráfica (Tkinter) que responde preguntas sobre los servicios, precios y horarios de una peluquería usando la API de Google Gemini.

**Instalación**
pip install -r requirements.txt

Crea un archivo .env con tu clave de Gemini:
API_KEY=tu_clave_aqui

**Uso**
python asistente_gui.py

**Archivos**

asistente_gui.py: programa principal.
servicios.txt: información de la peluquería que usa la IA.
requirements.txt: dependencias.
